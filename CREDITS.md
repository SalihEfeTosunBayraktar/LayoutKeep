carries, because a project that ships someone else's code owes them the sentence.

## Fonts

All bundled under the **SIL Open Font License 1.1**. The licence text for each travels with it in
[`src/layoutkeep/assets/fonts/licenses/`](src/layoutkeep/assets/fonts/licenses/).

| Font | Why it is here |
|---|---|
| [Tinos](https://fonts.google.com/specimen/Tinos) | Metric-compatible with Times New Roman |
| [Arimo](https://fonts.google.com/specimen/Arimo) | Metric-compatible with Arial |
| [Cousine](https://fonts.google.com/specimen/Cousine) | Metric-compatible with Courier New |
| [Caladea](https://fonts.google.com/specimen/Caladea) | Metric-compatible with Cambria |
| [Carlito](https://fonts.google.com/specimen/Carlito) | Metric-compatible with Calibri |
| [Noto Sans / Noto Serif](https://fonts.google.com/noto) | The fallback when nothing else covers the target language's glyphs |

Metric compatibility is the point: substituting a font of different widths moves every line of a
document, which is the thing this project exists not to do.

## Interface

The icons are drawn for this project as inline SVG
([`src/layoutkeep/ui/icons.py`](src/layoutkeep/ui/icons.py)) in the visual idiom of
[Feather](https://feathericons.com/) (MIT) — 24×24, 2px strokes, round caps and joins. No icon
file is copied in.

The published comparison page uses [IBM Plex](https://github.com/IBM/plex) (SIL OFL 1.1), loaded
from Google Fonts rather than bundled.

## Sample documents

Every sample and fixture in this repository is generated by code in `tools/` and
`tests/fixtures/` — `make_academic_paper.py`, `make_sample_document.py`, the fixture builders.
Nothing was taken from a real publication, so the repository can publish the documents and the
images made from them without a licence question. The academic paper's authors, journal, figures
and measurements are all invented.

## Measurement sources (not redistributed)

The lossless work is measured on real documents, kept out of the repository in
`_artifacts/heldout/sources/` and named in [`docs/campaign/HELDOUT.md`](docs/campaign/HELDOUT.md).
They are read, translated and audited here; nothing of them is published except the findings.
Saying which documents those findings came from is part of the finding:

The model used to test the pipeline locally is **Gemma** (`google/gemma-4-e4b`, quantised GGUF)
served by [LM Studio](https://lmstudio.ai/). Its weights are used under Google's Gemma terms of
use and are not redistributed here — the model file lives on the machine that runs the tests.

## Practice

The working rules this project is held to — say what you measured, do not report a failing test
as passing, prefer the simple change — are shaped by Andrej Karpathy's published notes on where
LLM-written code goes wrong, by way of the
[andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills) collection (MIT).

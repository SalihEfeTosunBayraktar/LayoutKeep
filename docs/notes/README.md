# Working notes

These are working notes, not documentation. They are **in Turkish**, they are dated, and parts of
them describe work that was later measured and found wanting — the image and EPUB conversions
they design are locked in the current build (see [`../ENGINE-ARCHITECTURE.md`](../ENGINE-ARCHITECTURE.md)).

They are kept because the analysis in them is real and the engine work ahead will need it. They
are not kept as a description of how the project behaves today. For that, read the
[README](../../README.md), the [contract](../CONTRACT.md) and the
[measurements](../BENCHMARK.md).

| File | What it is |
|---|---|
| `image-pipeline-audit.md` | What the image pipeline did at the time it was audited |
| `image-translation-architecture.md` | The design that pipeline was built to |
| `image-translation-providers.md` | Survey of OCR and inpainting options considered |
| `image-translation-backlog.md` | What was left undone |
